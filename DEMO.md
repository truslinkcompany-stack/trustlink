# Приёмка KPI № 1 и демо (15.10)

## Чек-лист KPI
| Критерий | Как проверить | Результат |
|---|---|---|
| А. Путь от фото до PDF без ручных правок | Снять фото на телефоне, нажать «Отправить», скачать PDF. Ничего не редактируя в базе и коде | |
| Б1. Время в сертификате ±1 минута | Сравнить «Дату и время» в PDF с часами телефона в момент съёмки (5 тестов) | |
| Б2. Точка совпадает с местом (на улице ≤100 м) | Снять на улице, открыть координаты из PDF в картах, измерить расстояние до места съёмки. В форме точность должна быть ≤100 м | |
| В. Нет загрузки из галереи, только камера | На странице нет выбора файла. Проверить на iPhone и Android | |
| Г. QR, ссылка и PDF читаются на iPhone и Android | Открыть PDF, отсканировать QR второй телефон, открыть ссылку из сообщения | |
| Г2. По QR открывается сертификат | После сканирования видна страница «Подтверждение выполнения» со статусом «ПОДТВЕРЖДЕНО» | |

## Сценарий демо (5 минут)
1. Открыть сайт на телефоне: главная, «О проекте», «Новости».
2. «Открыть камеру», дождаться координат (точность ≤100 м), снять фото.
3. Заполнить только «Выполнено», остальное оставить пустым. Отправить.
4. Скачать PDF: показать, что «Проект» и «Автор» в нём отсутствуют.
5. Снять второй сертификат с полностью заполненными полями.
6. Отсканировать QR вторым телефоном: открывается сертификат, статус «ПОДТВЕРЖДЕНО».
7. Негативный тест: открыть `/verify/00000000-0000-0000-0000-000000000000` : «НЕ ПОДТВЕРЖДЕНО».
8. Показать, что прямая ссылка на файл в хранилище Supabase не открывается (bucket закрыт).

## Перед демо
- 5 тестовых сертификатов на iPhone и Android, на улице и в помещении.
- Проверить, что в Vercel заданы все переменные из `.env.example`.
- Новости: положить файлы `.md` в `content/news`.
